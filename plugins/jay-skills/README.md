# jay-skills

비개발자를 위한 Claude Code 도구 모음입니다. 개발 경험이 없어도 AI와 함께 작은 도구를
만들 수 있도록, **처음 준비 / git·GitHub 사용 / 쉬운 결과 보고** 세 가지를 돕습니다.

한국어 사용자를 대상으로 만들었습니다. 베타 버전이에요.

## 설치

```
/plugin marketplace add daum-hr/jay-plugins
/plugin install jay-skills@jay-plugins
```

자세한 절차와 zip 수동 설치 방법은 [`INSTALL.md`](INSTALL.md) 를 봐주세요.

## 무엇이 들어 있나요

**처음 준비**

- `welcome` — git 설치·내 이름·팀 저장소 연결이 됐는지 확인하고 빠진 것만 채웁니다

**git · GitHub (핵심)**

- `status` — "지금 무슨 상태예요?" 읽기 전용 진단. 어디서부터 할지 모를 때 먼저
- `github-login` — 올리기가 거부되거나 비밀번호를 안 받아줄 때
- `push` — 내 작업을 팀 저장소에 push (main 대신 안전한 작업 브랜치를 자동 생성)
- `pull` — 동료가 올린 최신 작업 받아오기
- `fix-conflict` — 충돌을 조각별로 "내 버전 / 동료 버전" 골라가며 정리
- `undo` — 실수 되돌리기 (잘못 커밋 / main에 커밋 / 잠깐 치워두기)
- `pr` — 내 작업을 동료에게 확인 요청(PR)으로 올리고, 확인되면 팀 최종본에 merge
- `review-pr` — 동료가 보낸 확인 요청(PR)을 쉬운 말로 요약해서 검토·승인·의견 남기기

**작업 기록**

- `commit` — 알아서 메시지를 만들어 커밋
- `explain` — 어려운 파일·에러 메시지를 쉬운 말로
- `handoff` — 잠깐 쉬기 전에 지금 상황 메모
- `record` — 중요한 작업·결정을 기록으로

## 설계 원칙

- **되돌릴 수 없는 일은 먼저 물어본다.** 모든 흐름은 중간에 멈춰도 이어서 할 수 있는
  상태로만 남깁니다.
- **강제 덮어쓰기는 하지 않는다.** `push --force`, `reset --hard`, 이미 올린 이력 고치기는
  어떤 상황에서도 쓰지 않습니다.
- **기술 선택은 알아서, 내용 선택은 사람이.** merge 방식이나 브랜치 이름 규칙은 도구가
  정하고, "어느 쪽 내용을 남길지"는 반드시 사용자가 고릅니다.
- **개발자가 없는 팀을 가정합니다.** 확인도 merge도 동료끼리 직접 합니다. 막혔을 때는
  "개발자에게 맡기세요" 대신, 지금 상태를 그대로 두고 누구에게 물어보면 되는지를
  알려줍니다.
- **결과는 쉬운 순서로.** 한 줄 결론 → 쉬운 설명 → 기술 상세는 요청할 때만.
